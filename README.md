Circle Packer
=============

An animated demo showing circles packed and arranged with a pleasing color palette. See the animation below:

![@demo.gif](./demo.gif)

What this is
------------

A small visualization / experiment that generates and displays packed circles of varying sizes and colors. The included `demo.gif` shows a rendered example of the algorithm in action.

How to view
-----------

- Open `demo.gif` in an image viewer or your OS file browser to see the animation.
- If the project contains source code to run the visualization, open the repository in your preferred editor and follow any project-specific instructions (for example `npm install` / `npm start` if applicable).
